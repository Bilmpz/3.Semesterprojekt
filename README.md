# Cendo – analyse af viderestillinger

P3-projekt, AAU (efterår 2026) · Gruppe 1

Prototype, der finder årsagen til, at Cendos AI-agenter viderestiller samtaler, grupperer dem og viser dem i et dashboard.

**Gruppe:** Jonathan Rosing · Oliver Løbel · Horst Krewald · Ida Jakobsen · Amalie Bak · Mathias Hansen · Nikolaj Elbæk
**Vejleder:** Josephine Marie Bakka

**Stack:** React + Vite · Java Spring Boot · Neo4j · Ollama (Gemma 3 12B, paraphrase-multilingual)

Kom i gang: se `aaben_frontend.md` og `docs/`.
